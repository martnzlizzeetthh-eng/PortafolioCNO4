File Path Traversal - Traversal Sequences Stripped Non-Recursively

Laboratorio Práctico de PortSwigger Web Security Academy

01. Marco Teórico y Fundamentación Técnica

File Path Traversal mediante Eliminación No Recursiva es una técnica de evasión de filtros en la que la aplicación intenta sanitizar la entrada del usuario eliminando las secuencias de navegación relativa (como ../) mediante un reemplazo simple de cadenas, pero comete el error de no aplicarlo de forma recursiva.

Mecanismo de la Vulnerabilidad

Cuando un filtro de seguridad simplemente busca la secuencia ../ y la reemplaza por una cadena vacía una sola vez (por ejemplo, con un replace("../", "") básico), es posible eludir la protección anidando las secuencias.

Al enviar la secuencia ....//, el filtro elimina la cadena ../ central, provocando que los caracteres restantes (.. a la izquierda y / a la derecha) se unan automáticamente, reconstruyendo de nuevo la secuencia ../ antes de pasar la ruta al sistema de archivos.

Impacto (Triada CIA y OWASP)

  • A01:2021 - Broken Access Control (OWASP Top 10): Ineficacia en la sanitización de entradas que conduce a la evasión de mecanismos de control de acceso.
  • Confidencialidad: Permite la lectura no autorizada de archivos del sistema como /etc/passwd mediante la manipulación de secuencias anidadas.
  • Principio de Defensa: Evitar la sanitización manual basada en eliminación de cadenas. En su lugar, se deben usar identificadores fijos, listas blancas o resolver el camino canónico y validar que permanezca en el directorio raíz permitido.

02. Procedimiento Técnico y Uso de Burp Suite

A continuación se detalla el procedimiento paso a paso para identificar y explotar el bypass de sanitización no recursiva:

  1. Intercepción de Petición: Se navega por la tienda de aplicaciones y se intercepta con Burp Proxy la solicitud GET enviada para cargar la imagen de un producto.
  2. Transferencia a Repeater: Se envía la petición GET /image?filename=... a Burp Repeater (Ctrl + R) para pruebas iterativas.
  3. Prueba de Traversal Básico (Bloqueado/Sanitizado): Al inyectar ../../../etc/passwd, la aplicación elimina las secuencias ../ devolviendo un error de archivo no encontrado al intentar cargar etc/passwd.
  4. Inyección del Payload Anidado: Se modifica el parámetro filename reemplazando cada ../ por la secuencia anidada ....//, quedando como payload: ....//....//....//etc/passwd.
  5. Confirmación de Explotación: Al enviar la petición, el filtro elimina la porción central de cada bloque y reconstruye la ruta ../../../etc/passwd, devolviendo con éxito el contenido del archivo /etc/passwd y la respuesta 200 OK.

03. Documentación Técnica del Laboratorio

Lab: File path traversal, traversal sequences stripped non-recursively

URL del Laboratorio: PortSwigger Web Security Academy - Sequences Stripped Non-Recursively

Alteración de la Petición HTTP:

-- Petición Original:
GET /image?filename=54.jpg HTTP/1.1
Host: lab-id.web-security-academy.net

-- Petición Alterada con Payload (Secuencias Anidadas):
GET /image?filename=....//....//....//etc/passwd HTTP/1.1
Host: lab-id.web-security-academy.net

Explicación Técnica del Payload:

Payload: ....//....//....//etc/passwd
La aplicación procesa la entrada ejecutando un reemplazo simple no recursivo: sustituye cada coincidencia de ../ por una cadena vacía. Al procesar ....//, se extrae el patrón ../ del medio, juntando los caracteres sobrantes (.. + /) para formar nuevamente ../. Así, tras el paso del filtro, la ruta final evaluada por el servidor se convierte en ../../../etc/passwd.

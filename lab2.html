File Path Traversal - Absolute Path Bypass

Laboratorio Práctico de PortSwigger Web Security Academy

01. Marco Teórico y Fundamentación Técnica

File Path Traversal mediante Bypass de Ruta Absoluta es una variante de Directory Traversal en la cual la aplicación intenta bloquear o sanitizar secuencias relativas como ../, pero falla al no validar el uso de rutas absolutas completas del sistema operativo.

Mecanismo de la Vulnerabilidad

Muchas aplicaciones implementan filtros sencillos para mitigar Path Traversal detectando y bloqueando patrones de navegación relativa (../ o ..\). Sin embargo, si el código subyacente pasa el valor del parámetro directamente a funciones de lectura de archivos (como file_get_contents o open()) que aceptan rutas absolutas, el filtro relativo es completamente inefectivo.

Al enviar una ruta absoluta directa como /etc/passwd, el sistema de archivos del servidor resuelve la dirección desde el directorio raíz directamente, ignorando la necesidad de retroceder niveles en el árbol de directorios.

Impacto (Triada CIA y OWASP)

  • A01:2021 - Broken Access Control (OWASP Top 10): Bypass de defensas perimetrales e ineficiencia en la validación de entradas.
  • Confidencialidad: Acceso no autorizado a archivos sensibles del sistema operativo mediante rutas directas.
  • Principio de Defensa: Implementar listas blancas estrictas de nombres de archivo permitidos o resolver y verificar mediante canonicidad que la ruta final permanezca dentro del directorio base autorizado (e.g., canonicalPath.startsWith(baseDir)).

02. Procedimiento Técnico y Uso de Burp Suite

A continuación se detalla el procedimiento paso a paso para identificar y explotar el bypass de ruta absoluta en la aplicación:

  1. Intercepción de Petición: Se navega por la tienda virtual y se intercepta la petición HTTP enviada al cargar una imagen de producto a través de Burp Proxy Intercept.
  2. Identificación del Parámetro: Se observa la petición GET /image?filename=53.jpg y se envía a Burp Repeater (Ctrl + R).
  3. Prueba de Traversal Relativo (Bloqueado): Al intentar usar ../../../etc/passwd, la aplicación responde con un error o bloquea la petición debido a la presencia de secuencias ../.
  4. Evasión con Ruta Absoluta: Se modifica el parámetro filename asignando directamente la ruta absoluta del archivo objetivo: /etc/passwd.
  5. Confirmación de la Explotación: Al enviar la petición modificada, el servidor procesa la ruta absoluta directamente y retorna el contenido de /etc/passwd en el cuerpo de la respuesta HTTP con estado 200 OK.

03. Documentación Técnica del Laboratorio

Lab: File path traversal, traversal sequences blocked with absolute path bypass

URL del Laboratorio: PortSwigger Web Security Academy - Absolute Path Bypass

Alteración de la Petición HTTP:

-- Petición Original:
GET /image?filename=53.jpg HTTP/1.1
Host: lab-id.web-security-academy.net

-- Petición Alterada con Payload (Ruta Absoluta):
GET /image?filename=/etc/passwd HTTP/1.1
Host: lab-id.web-security-academy.net

Explicación Técnica del Payload:

Payload: /etc/passwd
Debido a que la aplicación bloquea específicamente las secuencias de retroceso relativo (../), el payload utiliza la ruta absoluta directa. Dado que el parámetro del usuario es tratado directamente por el sistema de archivos sin verificar si es relativo o absoluto, la raíz / sobreescribe cualquier prefijo de directorio implícito y accede de forma directa al archivo del sistema.
